# css — Định dạng giao diện

Chứa tệp .css để điều chỉnh bố cục, màu sắc, khoảng cách và kiểu chữ.

Tệp gợi ý:
- main.css: kiểu chung toàn hệ thống.
- layout.css: header, menu, nội dung và footer.
- books.css: giao diện tra cứu và quản lý sách.
- responsive.css: bố cục cho điện thoại, máy tính bảng.

Ưu tiên tái sử dụng lớp CSS; tránh sao chép cùng một kiểu sang nhiều trang. Thử giao diện trên màn hình nhỏ và lớn sau khi sửa.
