# images — Hình ảnh giao diện

Chứa logo, biểu tượng, ảnh minh họa và bìa sách mẫu, ví dụ logo.png, empty-books.svg, sample-cover.jpg.

Đặt tên rõ nghĩa và tối ưu dung lượng. Chỉ dùng hình ảnh có quyền sử dụng. Tệp người dùng tải lên cần cơ chế kiểm tra loại tệp, dung lượng và quyền truy cập riêng; không mặc định lưu tệp tải lên tùy ý tại thư mục tài nguyên công khai này.
