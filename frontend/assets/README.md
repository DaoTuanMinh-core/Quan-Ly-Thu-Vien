# assets — Tài nguyên giao diện

Chứa tài nguyên tĩnh được các trang dùng chung:
- css/: bố cục, màu sắc, kiểu chữ và giao diện trên các kích thước màn hình.
- js/: tương tác, kiểm tra biểu mẫu và gọi API.
- images/: logo, biểu tượng và hình ảnh mẫu.

Đặt tên dễ hiểu như main.css, books.js, logo.png. Không đặt mã xử lý PHP, dữ liệu đăng nhập hay bản sao cơ sở dữ liệu tại đây.
