# js — Tương tác phía trình duyệt

Chứa tệp JavaScript xử lý sự kiện và cập nhật giao diện.

Tệp gợi ý:
- main.js: thao tác menu và thông báo dùng chung.
- books.js: tìm kiếm, phân trang và gọi API sách.
- borrow.js: biểu mẫu mượn/trả, thông báo kết quả.
- validation.js: kiểm tra biểu mẫu để người dùng nhập thuận tiện.

Xử lý trạng thái đang tải và lỗi khi gọi backend. Không lưu mật khẩu cơ sở dữ liệu hoặc quyết định quyền truy cập trong JavaScript; backend phải kiểm tra quyền và dữ liệu đầu vào.
