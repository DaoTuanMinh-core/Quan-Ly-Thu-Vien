# Module local khớp báo cáo Lab 8

Sao chép nguyên mã local CNPMTH đã mô tả trong báo cáo: Map, AppError, createAuthService/createApp, giới hạn JSON 10 KB, username 3–50 ký tự và password tối đa 72 byte. Có 20 test Jest/Supertest, dữ liệu riêng mỗi test.

Từ root repository: npm.cmd run setup:local; npm.cmd run test:local; npm.cmd run start:local. Cổng mặc định 3000. Kết quả ở docs/evidence/local. Module này không thay thế hoặc ghi đè mã của thành viên tại labs/lab08-auth.

Chưa có database, token/session, phân quyền, rate limiting hay nghiệp vụ mượn/trả/ebook. Cả hai bản chỉ phục vụ thực hành Lab 8.
