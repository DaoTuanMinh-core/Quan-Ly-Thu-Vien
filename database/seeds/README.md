# seeds — Dữ liệu mẫu

Chứa SQL hoặc mã PHP tạo dữ liệu giả phục vụ trình diễn và kiểm thử.

Tệp gợi ý: 001_categories.sql, 002_books.sql, 003_readers.sql, 004_loans.sql.

Chạy sau khi cấu trúc cơ sở dữ liệu đã được tạo, đúng thứ tự khóa ngoại. Ghi rõ seed có thể chạy lặp hay chỉ chạy trên cơ sở dữ liệu mới. Dùng dữ liệu giả, không dùng thông tin độc giả thật. Nếu tạo tài khoản mẫu, lưu mật khẩu đã băm bằng cơ chế phù hợp của PHP và chỉ sử dụng trong môi trường phát triển.
