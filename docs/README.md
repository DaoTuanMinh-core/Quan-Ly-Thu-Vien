# docs — Tài liệu dự án

Chứa tài liệu cho thành viên phát triển, người kiểm thử và người sử dụng.

- requirements/: yêu cầu chức năng, vai trò và quy định nghiệp vụ.
- design/: kiến trúc, thiết kế dữ liệu, API và giao diện.
- user-guide/: hướng dẫn cài đặt, sử dụng và xử lý lỗi thường gặp.

Có thể dùng Markdown, PDF, DOCX hoặc sơ đồ. Ưu tiên Markdown cho nội dung cần theo dõi thay đổi bằng Git. Ghi ngày hoặc phiên bản khi cần và cập nhật tài liệu theo hành vi đã triển khai.
