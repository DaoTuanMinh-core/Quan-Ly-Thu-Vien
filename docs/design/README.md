# design — Thiết kế hệ thống

Chứa mô tả cách hiện thực các yêu cầu.

Tệp gợi ý:
- architecture.md: luồng frontend → backend → MySQL.
- database-design.md: bảng, khóa, quan hệ, chỉ mục; kèm sơ đồ ERD.
- api-spec.md: URL, phương thức, tham số, phản hồi và quyền truy cập.
- ui-wireframes/: bản phác thảo các màn hình nếu cần.
- sequence-diagrams.md: trình tự xử lý mượn/trả và tình huống đồng thời.

Liên kết thiết kế với mã yêu cầu. Ghi rõ sự khác nhau giữa đầu sách và từng bản sách để quản lý tồn kho, trạng thái và phiếu mượn chính xác. Cập nhật khi cấu trúc dữ liệu hoặc API thay đổi.
