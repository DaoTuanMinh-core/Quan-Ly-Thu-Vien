# requirements — Yêu cầu phần mềm

Chứa mô tả hệ thống phải làm gì và điều kiện chấp nhận.

Tệp gợi ý:
- functional-requirements.md: tra cứu, quản lý sách/độc giả, mượn/trả, thống kê.
- business-rules.md: hạn mức mượn, thời hạn, gia hạn và phạt trễ.
- roles-permissions.md: quyền của độc giả, thủ thư và quản trị viên.
- use-cases.md: luồng chính, ngoại lệ và điều kiện trước/sau.

Đánh mã yêu cầu như FR-01 để liên kết với thiết kế và kiểm thử. Phân biệt quy định đã thống nhất với đề xuất chưa chốt; không tự mặc định số ngày mượn hoặc mức tiền phạt.
